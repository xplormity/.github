# Xplormity

An independent AI lab. We build open developer tools and publish reproducible benchmarks for local AI.

- **[Every Local AI](https://everylocalai.com)**: a free directory of self-hosted AI with VRAM math, per-GPU speed data and the NewsShorts-Bench benchmark series.
- **[Xplormity Lab](https://xplormity.com/lab)**: open developer tools, starting with [SearchDock CLI](https://github.com/xplormityai/searchdock-cli), which reads Google Search Console analytics, inspects indexed URLs and monitors sitemaps from a terminal or an AI agent.
- **[Research](https://xplormity.com/research)**: plain-language summaries of what our benchmarks found.

Website: [xplormity.com](https://xplormity.com)
